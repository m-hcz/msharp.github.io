SG Civil Tools

Add-on for Autodesk Civil 3D. Helps users to design linear structures based on Czech standards.

Features

Staking point generator: Generates staking points along a corridor and exports them to COGO and XLS.

Alignment table: Lists stations, coordinates and radii of an alignment and exports the table to XLS, TXT or DWG.

CC Cad Tools

 Windows

CC Cad Tools

Add-on for all Autodesk AutoCAD-based products. Implements features that are not available in the software.

Features

File Manager: Pins drawings, folders and templates in one palette for quick opening.

Milling & Stripping: Creates a stripped surface from a selected surface and boundary layers.

SG Civil BIM Complete

Add-on for Autodesk Civil 3D. Helps users to create and validate BIM data.

SG Civil Design Validator

 Windows

SG Civil Design Validator

Add-on for Autodesk Civil 3D. Helps users to validate their design based on Czech standards.

Features

SlopeGuard: Validates the designed slopes of a corridor against the design speed and lists errors and warnings by station.

Input parameters: Station ranges, design speed and corridor feature lines are set before validation.
